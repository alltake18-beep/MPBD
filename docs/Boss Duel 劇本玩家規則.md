# Boss Duel 劇本玩家規則

更新日期：2026-09-18
狀態：已套用正式版；`natural-story-preset-v16` 已重產 240,000 筆並完成全量重播

## 1. 目的與適用範圍

本規格只定義「離線產生正式劇本時，負責操作牌局的劇本玩家」如何選牌、換牌、FIGHT、FOLD 與進入下一回合。

本次不調整下列項目：

- 一般玩家在遊戲內看到的自動理牌與初始自動保留。
- 一般玩家手動改牌、FIGHT 或 FOLD 的權利。
- 機率工具內聰明、白嫖、極端等模擬玩家行為。
- BOSS 星級出現率、BOSS 數值與換王規則。
- 抑制、個人劇本水池、三候選配籤及派彩補正。

正式遊戲中的 BOSS 仍依機率工具設定的 BOSS 出現率抽取。離線產線為補足 8 星 × 3 分類 × 每類 10,000 筆而暫時指定缺額星級，不屬於劇本玩家的判斷，也不改變正式遊戲的 BOSS 出現率。

## 2. 核心原則

劇本玩家不是模型或生成式 AI，而是一套固定規則。同一組可見輸入必須得到唯一且可重播的結果。

每回合在第一次換牌前，劇本玩家必須先選定一條互斥的理牌路線：

- 走一般牌型路線時，只保留該牌型的核心牌，取消不屬於該路線的暴擊／固傷牌。
- 走暴擊或固傷路線時，綁定效果的實體牌必須包含在該路線的核心保留牌內；與該路線不相容的原牌型核心必須取消。
- 不得把一般牌型核心與無關的暴擊／固傷牌合併成一組保留牌後再換牌。
- 選定路線後，該回合不得重新執行起手選路，也不得因後續抽牌結果改選另一條起手路線。

共用理牌核心只負責提供合法牌型候選。劇本玩家規則負責從候選中選一條路線，不得另做第二套撲克牌型判斷。

## 3. 劇本玩家可以使用的資料

劇本玩家每次只能讀取當下已公開或已確定的資料：

- 本回合初始六張玩家手牌。
- 每張牌是否綁定暴擊或固傷。
- 本回合已抽出的兩張魔法卡種類。
- 鬼牌是否存在。
- 共用理牌核心回傳的所有合法候選牌型及其核心牌。
- 目前已使用的免費與付費換牌次數。
- 目前 BOSS HP、回合數及回合上限。
- 目前牌堆是否仍符合最低剩餘張數限制。

劇本玩家不得讀取或利用：

- 尚未抽出的牌或完整牌堆未來順序。
- 尚未公開的 BOSS 手牌。
- 後續回合的手牌與魔法卡。
- 劇本最後會被分成贏多、贏或輸。
- 劇本最後總派彩、總實付或淨結果。
- 個人劇本水池餘額。
- 抑制是否會啟動及抑制後數值。
- RTP 設定與三候選籤數。
- 為了取得指定分類而倒推或改變操作。

暴擊與固傷的實際數值在比牌前仍視為未公開資訊。選路只能辨識效果種類，不得比較隱藏數值。

## 4. 起手候選路線

每回合發出六張手牌並套用兩張魔法卡後，劇本玩家建立以下候選路線。

### 4.1 一般牌型路線

使用共用理牌核心的最高優先牌型候選，但只取 `coreCards`，不得加入理牌核心為一般玩家補上的 `extraCards`。

如果暴擊或固傷綁定牌本來就在 `coreCards` 內，該效果自然屬於這條牌型路線，不算額外攜帶。

### 4.2 暴擊路線

針對每一張綁定暴擊的實體牌，從共用理牌核心的候選中找出所有包含該實體牌的候選。每個候選的保留集合只能是該候選的核心牌。

如果暴擊牌無法與其他手牌形成兩張以上的合法核心，仍建立「單張暴擊」候選，只保留暴擊牌；有鬼牌時一併保留鬼牌。

### 4.3 固傷路線

規則與暴擊路線相同，但綁定牌改為固傷牌。

如果同一張實體牌同時綁定暴擊與固傷，只建立一組以該實體牌為錨點的候選，不得重複加入同一張牌。

### 4.4 牌型增傷路線

本回合若抽到三條、四條、順子、同花或葫蘆增傷魔法卡，所有最終目標與該魔法卡相符的合法候選都可成為候選路線。

未完成候選依最終目標配對：

- 一對、兩對、三條可對應三條／四條／葫蘆目標時，以候選本身已標示的目標為準。
- 兩張／三張／四張同花與同花順候選可對應同花或同花順目標。
- 兩張／三張／四張順子候選可對應順子目標。

候選必須由共用理牌核心實際回傳，不能為了魔法卡自行拼出理牌核心不存在的牌型。

### 4.5 鬼牌

鬼牌必須出現在所有可選路線的保留集合內。含鬼牌時，只能使用真正包含鬼牌的合法牌型候選，不能把鬼牌額外塞入另一條不含鬼牌的候選。

## 5. 路線等級

候選路線依起手完成度分成五級：

| 等級 | 牌型候選 |
|---:|---|
| 4 | 皇家同花順、同花順、四條、葫蘆、同花、順子 |
| 3 | 差一張同花順、四張同花、差一張順子、三條、兩對 |
| 2 | 一對、三張同花、三張連號 |
| 1 | 兩張同花、兩張順子 |
| 0 | 單張暴擊、單張固傷、鬼牌或沒有正式牌型核心 |

同一候選不因暴擊、固傷或牌型增傷而提高路線等級。魔法卡只用於同級候選的固定選擇，不得讓較弱路線跨級擊敗明顯較強的牌型。

## 6. 唯一選路排序

所有候選依下列順序比較，遇到第一個不同項目就決定，不再繼續比較：

1. 路線等級較高者優先。
2. 可啟動的本回合魔法卡種類數較多者優先。
3. 同一張實體牌同時帶暴擊與固傷者優先。
4. 可啟動暴擊者優先。
5. 可啟動固傷者優先。
6. 依共用理牌核心既有牌型優先序決定。
7. 核心保留牌張數較多者優先。
8. 仍相同時，依效果綁定牌在原始六張手牌中的位置，由前到後決定。
9. 仍相同時，依保留牌 ID 排序後的字串順序決定。

「可啟動魔法卡種類數」只計算這條候選確實能使用的魔法：

- 暴擊／固傷：綁定效果的實體牌包含在候選核心內。
- 牌型增傷：候選的最終目標與本回合牌型增傷魔法相符。
- 金幣與免費換牌不影響起手選路。
- 鬼牌是所有路線共同遵守的必留條件，不作為同級加分。

完成排序後只保留第一名，其他候選全部捨棄。不得進入換牌後再比較其他路線。

## 7. 路線鎖定與後續換牌

選定路線後，該路線的 `keepCardIds` 視為玩家已確認保留：

- 後續換牌不得取消已確認保留牌。
- 暴擊路線必須持續保留原本綁定暴擊的實體牌。
- 固傷路線必須持續保留原本綁定固傷的實體牌。
- 一般牌型路線如果已取消效果牌，該回合不得再回頭追該效果牌。
- 每次 REDRAW 後只允許共用理牌核心在保留原確認牌的前提下加入相容的新牌，或做現行允許的同點數合法替換。
- 皇家同花順、同花順或四條直接完成時，沿用現行唯一強制覆蓋規則；此時可以覆蓋原保留集合。

除上述強制完成例外外，不得重新執行第 4～6 節的起手選路。

## 8. 換牌次數與停止條件

起手路線選定後，以起手路線等級鎖定本回合的付費換牌上限。換牌後即使牌型升級，上限也不增加。

| 起手路線 | 最多付費換牌 |
|---|---:|
| 等級 4 的完成牌型 | 0 次 |
| 等級 3 | 3 次 |
| 等級 2、1 或 0 | 2 次 |

有鬼牌時，上述付費換牌上限減少 1 次，最低為 0 次。

免費換牌規則：

- 有免費換牌時先使用免費換牌。
- 免費換牌不占付費換牌次數。
- 免費換牌仍增加總換牌次數並推進費率階梯；免費換牌後的第一次付費換牌，依現行規則收第二階費用。

遇到以下任一條件立即停止換牌：

- 最終實際牌型已完成順子、同花、葫蘆、四條或同花順。
- 已達本回合付費換牌上限，且沒有未使用的免費換牌。
- 沒有可棄牌位置。
- 換牌後牌堆會低於既有 `deckStopCount`。
- 既有遊戲規則判定本次換牌無法合法完成。

劇本玩家不得因預測後續不划算、最終可能虧損或已經接近指定分類而提前停止換牌。

## 9. FIGHT、FOLD、平手與跨回合

停止換牌後，依最終實際牌型決定操作：

- 高牌：`FOLD`。
- 一對以上：`FIGHT`。

不得用 BOSS 未公開手牌、預估勝率、預估傷害或最終獲利修改此決定。

後續流程：

- 平手依現行規則在同一回合重新發牌，不重複收取該回合入場 Bet。
- 玩家獲勝時依現行牌型與魔法規則造成傷害。
- BOSS HP 歸零時結束劇本並進入派彩。
- BOSS 尚未死亡且仍有下一回合時，直接進入下一回合，重新抽本回合手牌與魔法卡，並重新執行一次起手選路。
- 回合數用完且 BOSS 未死亡時，劇本結束。
- 劇本玩家沒有 `STOP_LOSS` 或自行提前離開行為。

因此輸劇本可以自然包含多回合、多次實付換牌與多次 FIGHT，而不是大量只支付一次入場 Bet 就結束。

## 10. 操作範例

### 10.1 一對與暴擊三張同花同級

初始手牌：

- 10♥
- 10♠
- K♣，綁定暴擊
- Q♣
- 7♣
- 4♦

候選：

- 一般一對路線：等級 2，保留 10♥、10♠，啟動魔法數 0。
- 暴擊三張同花路線：等級 2，保留 K♣、Q♣、7♣，啟動魔法數 1。

兩者同級，暴擊路線可啟動一種魔法，因此選擇暴擊三張同花路線。最終只保留三張梅花；不得保留一對 10 再額外帶 K♣。

### 10.2 一對高於單張暴擊

初始手牌：

- 10♥
- 10♠
- K♣，綁定暴擊
- 8♦
- 5♠
- 3♥

候選：

- 一般一對路線：等級 2。
- 單張暴擊路線：等級 0。

選擇一般一對路線，保留 10♥、10♠，取消 K♣ 暴擊。

### 10.3 暴擊牌本來就在一對內

初始手牌包含 10♥暴擊與 10♠。一般一對路線的核心本來就包含暴擊牌，因此保留兩張 10，並自然啟動暴擊。這不是額外攜帶效果牌，也不需要另建混合路線。

### 10.4 兩對高於暴擊三張同花

- 一般兩對路線：等級 3。
- 暴擊三張同花路線：等級 2。

選擇兩對，取消不在兩對核心內的暴擊牌。魔法卡不能讓等級 2 路線跨級擊敗等級 3 路線。

### 10.5 同級路線同時啟動兩種魔法

兩條候選都是等級 2：

- 路線 A 包含暴擊牌，可啟動暴擊 1 種。
- 路線 B 包含另一張同時綁定暴擊與固傷的牌，可啟動暴擊、固傷 2 種。

選擇路線 B。選定後該雙效果實體牌整回合保持鎖定。

## 11. 工程實作要求

劇本玩家規則應集中在現行劇本規劃器，由正式產生器與正式重播共用。不得修改一般玩家的共用自動理牌結果來達成劇本玩家行為。

建議每回合保存下列稽核資料：

- `playerPolicyVersion`
- 起手六張牌 ID
- 本回合兩張魔法卡種類
- 全部候選路線的牌型、等級、核心牌 ID 與可啟動魔法
- 最終選中路線及每一層排序比較結果
- `initialKeepCardIds`
- 每次 REDRAW 的保留、棄牌、補牌與下一次保留 ID
- 是否發生皇家同花順／同花順／四條強制覆蓋
- 最終 FIGHT／FOLD
- 回合結束原因

相同 seed、相同設定與相同版本必須產生完全相同的候選、選路、換牌及結局。

## 12. 驗收案例

實作至少必須驗證：

1. 一對與無關暴擊牌不會合併保留。
2. 一對與暴擊三張同花同級時，選擇暴擊三張同花。
3. 一對高於單張暴擊時，保留一對並取消暴擊。
4. 暴擊牌本來在一對內時，一對路線可以正常啟動暴擊。
5. 兩對或三條不會被較低級的暴擊／固傷路線取代。
6. 同級候選可啟動兩種魔法時，優先於只啟動一種魔法。
7. 選定效果路線後，後續 REDRAW 不會取消效果綁定牌或改走起手一般牌型路線。
8. 選定一般路線並棄掉效果牌後，該回合不會重新追該效果牌。
9. 免費換牌會推進下一次付費費率，但不占付費換牌上限。
10. 劇本玩家不預看後續牌、不使用最終分類，也不執行 `STOP_LOSS`。
11. 相同 seed 重跑時，完整操作軌跡一致。
12. 新正式劇本仍滿足 8 星 × 3 分類 × 每類 10,000 筆，共 240,000 筆。
